花卷是一个个人AI助理项目，由 bot.py（Agent大脑，工具与对话逻辑）和 app.py（Flask 网页端）组成。
bot.py 实现了自研的 Function Calling 工具框架：工具登记表（TOOLS）+ 执行表（TOOL_FUNCS）+ 通用参数解包循环，新增一个工具只需三处登记。
项目支持多Agent派遣：主AI通过 dispatch_agent 工具把任务分派给翻译官、文案师、资料员、代码员四个子AI，线程池并行执行。
长文处理使用 map-reduce：超过3000字且带总结意图的内容会自动按约800字分块，并行派资料员提炼要点，再由主模型合并输出。
长期记忆使用 RAG：对话后自动提取值得记住的事实 → embedding 向量化 → 余弦相似度去重 → 每轮按当前问题现场检索 top-k 注入上下文。
模型幻觉治理：针对模型"口头答应、实际不调工具"的问题，实现规则引擎硬路由（正则意图识别 + tool_choice 强制调用），保证时间、天气、记账、开程序等指令真实执行。
电脑遥控类工具（开程序、截屏、锁屏）走白名单/确认制，Web 端有 ACCESS_TOKEN 访问门与 XSS 防护。
项目自带一键体检脚本（体检.py），可对 21 个工具与真 API 链路做自动化回归。
