## 主帖（直接复制改改）

**标题**：做了个把 Markdown 一键排成 PDF / PPT / Word 的小工具，带自检

**正文**：

被毕设/课设报告的排版折磨过几轮，就把这事做成了一个小 skill。

它做什么：

- 输入 Markdown（或一句话主题），一条命令出 **PDF / PPT / Word** 三份；
- PDF 带封面页、真表格、代码块、分页，中文字体是微软雅黑，报告风；
- PPT 是 16:9；Word 支持真表格和代码块。

和"直接丢给 ChatGPT"的区别，就两点：

1. 它产出的是**排版好的成品文件**，不是一段 markdown 再让你自己调；
2. 它带 `selfcheck.py` 自检——3 项全 PASS 才算"验过的"。这个生成器是从一个带 **66 项自动化回归**的项目里拆出来的。

仓库：https://github.com/mantou-fat/huajuan-ai-assistant （`skill-huajuan-docs` 目录）

学生作品，求拍砖。也想诚心问一句：**"文档一键生成"这种需求，到底真不真？** 你们平时会为"省排版时间"付钱吗？
