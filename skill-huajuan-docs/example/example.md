# STM32 光照闭环实验报告（示例）

> 作者：花卷 · 本文由花卷的 `make_pdf` 工具生成，仅作效果演示

## 一、实验目的

- 用 **STM32F103C8T6** 搭建光照闭环：光敏电阻测照度、PWM 调光。
- 把照度稳定在 `500~1500 lux`，误差 ≤ 2%。
- 练习 ADC 滤波、PI 控制、LCD 显示。

## 二、系统框图

- 目标照度 → PI 控制器 → PWM（1099Hz / 16 位）→ MOSFET → 6 颗白光 LED
- 光敏电阻分压 → ADC → 滤波换算 → 反馈回比较点

## 三、元件清单

| 元件 | 数量 | 作用 |
|---|---|---|
| STM32F103C8T6 | 1 | 主控 |
| 光敏电阻 GL5528 | 1 | 测照度 |
| 白光 LED | 6 | 补光灯 |
| 逻辑电平 MOSFET AO3400 | 1 | 低边开关 |

## 四、关键代码

```
// 增量式 PI：每 100ms 跑一次
float e = target - lux;
integral += e;
duty = Kp * e + Ki * integral;
```

## 五、测试结果

| 目标(lux) | 实测(lux) | 误差 |
|---|---|---|
| 500 | 498 | 0.4% |
| 1000 | 1003 | 0.3% |
| 1500 | 1492 | 0.5% |

## 六、结论

- 闭环在 `500~1500 lux` 内误差 ≤ 0.5%，达到 2% 要求。
- 1kΩ 分压 + 16 位 PWM 是精度的关键。
